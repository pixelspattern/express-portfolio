Express Portfolio

Personal portfolio website for INFR3120 – Web and Scripting Programming, Assignment 2. Built by Matthew Kiprenko (Ontario Tech University) with Node.js, Express and the EJS templating engine.

Live site: https://express-portfolio-43ni.onrender.com
GitHub repository: https://github.com/pixelspattern/express-portfolio

citations and external code
Express Generator – used to generate the project structure (https://expressjs.com/en/starter/generator.html).
Bootstrap 5.3.3 – CSS and JavaScript loaded from the jsDelivr CDN (https://getbootstrap.com). Navbar, grid and card components follow the Bootstrap documentation.
Font Awesome 6.5.1 – icons loaded from the cdnjs CDN (https://fontawesome.com).
Code from the INFR3120 lectures was used as a base for the Express and EJS setup.
